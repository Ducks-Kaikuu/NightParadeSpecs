# **NightParade エネミー・AI仕様書（最終確定版）**

## **1\. 基本コンセプト**

* **物理的なサンドバッグ（おもちゃ）:** 敵はプレイヤーの攻撃によって派手に吹き飛び、転がり、互いにぶつかり合う「物理オブジェクト」としての側面を強く持つ。  
* **UIレスな状態表現:** 敵の残りHPバーなどは表示せず、防護服の破損、モーションの変化、エフェクト（炎上・氷結）によって直感的に状況を伝える。  
* **妖怪 vs 人間（科学兵器）:** プレイヤーの超自然的な力に対し、敵は特殊な防護服や科学兵器、改造生体兵器で対抗する。

## **2\. 共通AIロジック**

### **2.1 ターゲット選択（ヘイト管理）**

1. **優先度1（設置物）:** 妖狐の「爆弾」やデコイなど、ヘイトを稼ぐオブジェクトを最優先で攻撃する。  
2. **優先度2（生存プレイヤー）:** 最も近くにいる「生存している」プレイヤー。  
3. **優先度3（高ダメージ）:** 一定時間内に高いダメージを与えてきたプレイヤー。

### **2.2 幽霊状態（ダウン時）の挙動**

* **ターゲット除外:** プレイヤーがHP0になり「幽霊状態」へ移行した瞬間、すべての敵AIはそのプレイヤーを即座に「無視」として扱う。  
* **死体撃ちの禁止:** ラグドール化した本体や移動する幽霊に対して、敵が攻撃を継続することはない。

## **3\. エネミーの階層（Tier）とギミック**

### **3.1 Tier 1: 群れ（Swarm / 防護服の兵士）**

* **一般兵:** 銃や警棒で攻撃。プレイヤーの体当たりや突っ張りで派手に飛ぶ。  
* **特殊武器兵:** 火炎放射兵（火）、冷却ガス兵（水/デバフ）、ネットガン兵（拘束）。  
* **特殊装甲兵:** 重装シールド兵（背後から斬）、耐熱ゼリー兵（火）、重力ブーツ兵（風で浮かす）。

### **3.2 Tier 2: 中ボス（Elite / 改造軍用犬）**

* **ギミック:** 背中に不安定な「化学燃料タンク」を背負っている。鎌鼬が「瞬身」で背後に回り込み破壊可能。

### **3.3 Tier 3: 大型ボス（人工キメラ）**

* **ギミック:** 属性シナジー（蒸気爆発等）を吸入させることでダウンを奪う環境利用型のボス。

## **4\. 物理적 推力と集団補正（押し合い仕様）**

重量級オブジェクト（ぬりかべ等）を敵が押し込む際の推力を以下の通り定義する。

### **4.1 敵1体あたりの基本推力**

* **Tier 1 (一般兵):** 推力 1.0  
* **Tier 2 (中ボス):** 推力 5.0（妖狐の爆弾と同等）  
* **Tier 3 (ボス):** 推力 15.0以上（河童の突っ張りを超える）

### **4.2 集団推力の計算（減衰補正）**

敵が複数体で同時に同じ方向へ押す場合、「集団による干渉と効率低下」を再現するため、以下の計算式と可変パラメータを適用する。

* **計算式:** 合計推力 \= 1.0 \+ (N \- 1\) × K  
  * **N:** 敵の数  
  * **K:** 集団効率係数（初期値: **0.2**）  
* **パラメータKの意図:** 開発・実装時にこの数値を調整することで、敵の「数による脅威」の度合いを変更可能。0.2は「1体増えるごとに20%分しか推力が加算されない」状態を指す。

| 敵の数 (Tier 1\) | 合計推力 (K=0.2) | プレイヤー側の対抗目安 |
| :---- | :---- | :---- |
| **1体** | **1.0** | 通常プレイヤー1名の体押し（推力1）で拮抗 |
| **5体** | **1.8** | 河童なら余裕。通常プレイヤー2名で押し勝てる |
| **10体** | **2.8** | 河童なら余裕。通常プレイヤー3名でほぼ拮抗 |
| **20体** | **4.8** | 妖狐の爆弾(5)と同等。河童1人でまだ押し勝てる |
| **50体** | **10.8** | **河童の突っ張り(10)とほぼ拮抗。** 天狗の風なしでは押し返せない |

## **6\. 開発用メモ：物理判定レイヤー**

* **敵攻撃レイヤー:** 幽霊状態のプレイヤーとは衝突しない。  
* **床・壁・穴レイヤー:** 幽霊本体（ラグドール）と常に衝突する。
